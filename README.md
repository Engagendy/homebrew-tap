# Homebrew Tap

Custom Homebrew tap for Engagendy macOS apps.

## Usage

```bash
brew tap Engagendy/tap
brew install --cask mpp-viewer
brew install --cask mclean
```

## Available Casks

| Cask | Description |
|------|-------------|
| `mpp-viewer` | Native macOS viewer for Microsoft Project (.mpp) files |
| `mclean` | Native macOS cleanup scanner for cache, temporary, old, and large files |
